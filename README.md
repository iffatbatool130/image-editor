PixelPro - AI Image Processing & Edge Detection
PixelPro is a web-based image processing and edge detection application developed using Python, Flask, OpenCV, and Pillow. It provides an intuitive interface for applying 20+ image processing filters and computer vision techniques directly through a web browser.
Academic Project: Programming for Artificial Intelligence
Instructor: Engr. Reema Qaiser Khan

Features
- Basic Adjustments: Brightness, Contrast, Saturation, Warmth and Coolness, Hue Adjustment
- Noise Removal: Gaussian Blur, Median Blur, Bilateral Filter, Mean Filter
- Edge Detection: Sobel Operator, Canny Edge Detection, Laplacian Operator, Laplacian of Gaussian (LoG)
- Sharpening: Sharpening Kernel, Unsharp Masking
- Artistic Effects: Grayscale, Image Inversion, Posterize, Sepia, Emboss, Otsu Thresholding, Pencil Sketch, Cartoon Effect, Pixelate / Mosaic
- Morphological Operations: Erosion, Dilation

How to Run Locally
Follow these steps to run PixelPro locally.
1. Clone the Repository
git clone https://github.com/iffatbatool130/image-editor.git
cd image-editor
2. Create a Virtual Environment
python -m venv venv
3. Activate the Environment
Windows:
venv\Scripts\activate
Mac/Linux:
source venv/bin/activate
4. Install Dependencies
pip install -r requirements.txt
5. Run the Application
python app.py
6. Open in Browser
Visit:
http://127.0.0.1:5000

The application can be deployed on Render.
Build Command:

Start Command:
